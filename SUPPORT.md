# Support

## Before opening an issue

- Read the [README](README.md), especially the requirements and troubleshooting sections.
- Search existing GitHub Issues to avoid duplicates.
- If the problem is about runtime state, ask Codex for `usage_runtime_status` and redact keys,
  tokens, cookies and personal usage values before posting it.

## Where to ask

- **Bug reports and feature requests:** use the repository's GitHub Issues.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Code of conduct concerns:** email [1561713602@qq.com](mailto:1561713602@qq.com).
- **Other project questions:** email [1561713602@qq.com](mailto:1561713602@qq.com).

## What not to post publicly

Do not paste API keys, website tokens, cookies, full `plugin.log` files, real balances, personal
token totals or screenshots of your personal data directory.

Usage Hub is a volunteer project. There is no guaranteed response time, but reproducible reports
with a clear environment and minimal reproduction are the quickest to investigate.
