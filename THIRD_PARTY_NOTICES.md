# Third-party notices

Codex Usage Hub does not bundle third-party runtime libraries. The distributed plugin uses Node.js
built-in modules, Windows PowerShell and WinForms, and the extension APIs provided by the browser
host.

The GitHub Actions referenced by `.github/workflows/ci.yml` are used only for continuous
integration and are not part of the plugin runtime. Their source and license terms are available
from their respective upstream repositories.

The project's own source code and assets are distributed under the terms in [LICENSE](LICENSE),
unless a file states otherwise.
